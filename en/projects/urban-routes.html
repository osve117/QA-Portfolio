CASE STUDY · TEST AUTOMATION

Urban Routes

E2E Automation with Python, Selenium and Pytest

An automated suite validating a taxi request workflow, from setting pickup and destination addresses to driver assignment.

Python Selenium WebDriver Pytest Page Object Model Google Chrome

01 · CONTEXT

What the project automates

Urban Routes is a web application for requesting rides. The suite aimed to automate the main user workflow: entering addresses, selecting the Comfort fare, registering a phone number, adding a card, writing a message, requesting extra services and waiting for driver information.

Automation ran with Selenium WebDriver and Pytest, keeping interface interaction logic separate from the test cases.

02 · ARCHITECTURE

How I organized the automation

Page Object Model

The UrbanRoutesPage class groups high-level actions such as setting the route, selecting options and reading interface values.

Separate selectors

Locators are centralized in UrbanRoutesSelectors, using strategies such as By.ID and By.XPATH.

Test data

The data used by the test cases is kept separate from the main logic to avoid repeating values within tests.

Readable tests

The cases use Page Object methods and direct assertions so that each test clearly describes the behavior it validates.

03 · AUTOMATED COVERAGE

Workflows covered

The suite contains nine automated tests covering different steps in the main ride request workflow.

1

Route configuration

Validation of pickup and destination fields by reading back their values.

2

Comfort fare selection

Interaction with the fare option and verification that it remains selected.

3

Ride details

Entry of a phone number, card details, a message for the driver and additional options.

4

Request and assignment

Validation of the workflow through finding a driver and displaying their information.

04 · RESULTS

Suite execution

The execution shown in the project includes 9 tests and finishes with 9 passed. The Pytest output shows the result of each scenario and the overall suite summary.

This project helped me practice Selenium, code organization, method reuse, separation of responsibilities and maintenance of an automated test suite.
